# Percorso autonomo

Esercizi fatti da solo prima del corso del Politecnico, come preparazione al machine learning. I dati sono quasi sempre di sensori e telemetria.

| Cartella | Argomento |
| --- | --- |
| `01-basi-python/` | sintassi, strutture dati, cicli, lettura e validazione di dati; mini-progetto: pipeline ETL di un'incubatrice |
| `02-classi-oop/` | classi, incapsulamento, polimorfismo; mini-progetti di pipeline a oggetti con test |
| `03-manipolazione-dati/` | analisi di efficienza, finestre scorrevoli |
| `04-algebra-e-modelli-lineari/` | vettorizzazione e broadcasting con NumPy, data leakage e validazione, discesa del gradiente e prime reti neurali |
| `05-pipeline-telemetria/` | un progetto di riepilogo che mette insieme i pezzi |
