# 03 - Allenamento per il progetto rilevamento guasti

A che punto siamo: progetto rilevamento guasti (Tennessee Eastman), passo 1 - preparazione (terminale, Git in due).

Qui vanno gli esercizi di allenamento, uno per cartella. Il codice finale del progetto sta nella repo `chemical-fault-detection`.

Le cartelle seguono i passi del progetto e valgono per entrambe le versioni: sprint (15 dicembre) e versione completa (febbraio). Nella versione completa gli esercizi tornano nella stessa cartella dell'argomento.

| Cartella | Argomento |
| --- | --- |
| 01-preparazione-terminale-git | terminale e Unix di base, Git in due da terminale, avvio di un progetto |
| 02-caricare-guardare-dati | leggere il file, pandas, primi grafici |
| 03-etichette-baseline | etichetta normale / guasto, X e y, baseline con soglia |
| 04-preparare-dati | split, normalizzazione, trapelamento |
| 05-primo-modello | fit e predict, scelta del modello |
| 06-valutare | metriche, matrice di confusione, scorciatoie |
| 07-piu-guasti | stesso codice su più guasti |
| 08-chiusura | test, docstring, README, prova sul computer del compagno |
