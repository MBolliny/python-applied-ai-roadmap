PROJECT 0: INCUBATOR TELEMETRY ETL PIPELINE
===========================================

OVERVIEW
Automated ETL pipeline designed to ingest, validate, and aggregate telemetry
streams generated by laboratory cell culture incubators. The system processes
raw tabular data, filters out corrupted sensor readings, enforces biological
operating limits, and exports consolidated session metrics to JSON.


DOMAIN CONSTRAINTS
- Target metrics: Temperature (°C) and pH.
- Biological validity thresholds:
  * Temperature : [30.0, 42.0] °C
  * pH          : [6.5, 8.0]
- Any sample falling outside these boundaries or containing unparseable
  types is discarded from metric calculations.


ARCHITECTURE & DATA FLOW
- Ingestion   : Memory-efficient line-by-line streaming of input files
                via pathlib.Path (O(1) memory footprint).
- Parsing     : Comma-separated tokenization with explicit casting
                (session_id: str, timestamp: int, temp: float, ph: float).
- Validation  : Fail-fast filtering against physical/chemical thresholds.
- Aggregation : In-place state accumulation over a nested heap dictionary
                tracking valid sample count, min/max temp, and running averages.
- Export      : Serialization of finalized metrics into a structured JSON
                report with float values rounded to 2 decimal places.


KEY IMPLEMENTATION PATTERNS
- Reference vs. Value semantics: Modifying shared accumulator dictionaries
  in-place (returning None) rather than reallocating nested structures.
- Defensive I/O: Automatic creation of missing parent directories before
  persisting reports to prevent unhandled FileNotFoundError crashes.
- Clean Separation of Concerns: Strict boundaries between raw text parsing,
  domain validation, in-memory aggregation, and final serialization.
